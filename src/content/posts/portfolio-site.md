ポートフォリオサイトを作りました。これまでの制作物や受賞、活動をまとめて、ここから見られるようにしています。

## 使ったもの

- **Astro**：静的サイトとして書き出せて、ブログを Markdown で書けるので選びました
- **GitHub Pages**：`main` にマージされると GitHub Actions でビルドして、自動で公開されます
- **Canvas**：ヘッダーの下で草花がゆれているのは、Canvas 2D で描いています。OS の「視差効果を減らす」設定がオンのときは止まります

日本語と英語のページは、1 つのデータファイルから同じ構成で作っています。

## 作り方

チーム開発と同じように、Issue を立ててブランチを切り、PR を出してマージする流れで進めました。1 機能 1 PR を目安にして、コミットもあとから読んで意味がわかる単位に分けています。

ソースコードは [GitHub](https://github.com/dkawasaki0308-cmyk/portfolio) で公開しています。

## これから

制作物の紹介や、勉強したことをブログに書いていく予定です。
